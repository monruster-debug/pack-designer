# Конструктор паков

Запуск: `node server.mjs`, затем http://127.0.0.1:5174/.
Предпросмотр суперадмина: http://127.0.0.1:5174/?admin.

## Публикация (заготовка)
На странице проверки добавлена кнопка «Опубликовать». После подключения сервера пак должен появляться в «Профиль → Кастомные паки», откуда пользователь сможет начать игру. Сейчас API не вызывается, успешная публикация не имитируется: готовый пак открывает информационное окно. Незаполненный пак блокирует действие.
JSON доступен только в режиме суперадмина, включая проверку в обработчике экспорта. Параметр admin — локальный предпросмотр интерфейса, не серверная авторизация. При интеграции проверять роль и права на backend.

Блок публикации оформлен карточкой: название пака, статус, количество карт, готовность разделов, путь в профиле и действия. JSON видит только суперадмин. Компоновка на узких экранах складывается в одну колонку.

# Конструктор паков

Рабочий репозиторий: https://github.com/monruster-debug/pack-designer.git.

Проверка перед завершением изменений: `npm ci`, затем `npm run lint` и `npm run build`. ESLint проверяет JavaScript приложения и скриптов на ошибки; собранный `dist/` и временные `.qa/` исключены.

После сборки: `node scripts/check-build-http.mjs` проверяет все файлы `dist/` через отдельный локальный сервер (порт 5196, переопределяется `CHECK_PORT`), чтение баннера и запрет записи без заголовка администратора. Нужен доступ к localhost.

Обязательные поля отмечены `*` и `aria-required`; ошибки связаны с полем через `aria-describedby` и `aria-invalid`. Описание карты обязательно для фактов, бункера, катастроф, особых и собственных типов; для профессии, биологии, здоровья, хобби и багажа оно необязательно. При включённых взаимоотношениях требуется минимум один игрок. Незавершённые паки сохраняются как черновики, публикация блокируется проверкой готовности.

Диагностика 25 ноября 2026: проверены переходы всех 12 разделов мастерской, каталог, пагинация библиотеки, формы карты и задач, защита несохранённых изменений, пользователи и история предупреждений, журнал, предложения, периоды статистики и форма на ширине 390 px. Исправлены метки и сообщения обязательных полей, повтор параметра площади бункера, сохранение нулевого числа участников взаимоотношений и гонка повторных загрузок изображений в админке. ESLint использует рекомендуемые правила с отдельными окружениями браузера и Node.js; обработчики с намеренно пустым `catch` допускаются.

Границы проверки: это локальный прототип. Публикация, серверные роли и игровая статистика требуют настоящей интеграции; параметр `?admin` и заголовок локального API не являются серверной авторизацией. Предложения сохраняются в браузере, их отправка команде не подключена. Проверки прототипа не подтверждают работу этих будущих серверных функций.

Сборка: `npm run build` — проверяет синтаксис и тесты, создаёт `dist/` со всеми модулями, стилями, данными и ресурсами. Содержимое `dist/` предназначено для корня статического хостинга. Сборка не требует установки зависимостей, используется Node.js.

Запуск: `node server.mjs`, затем http://127.0.0.1:5174/.
Предпросмотр суперадмина: http://127.0.0.1:5174/?admin.

Статистика паков доступна только суперадминам: пункт меню скрыт в обычном режиме, переход и рендер раздела проверяют роль.

Тематика «Другое» доступна в настройках пака и фильтрах каталога. «Выбрать из списка» доступно только в режиме суперадмина: фильтры по названию, паку и виду карты работают совместно, выбранные карты добавляются в соответствующие разделы. Особые условия и катастрофы используют свои отдельные редакторы. Собственные типы переносятся вместе с выбранными картами.

## Публикация (заготовка)
На странице проверки добавлена кнопка «Опубликовать». После подключения сервера пак должен появляться в «Профиль → Кастомные паки», откуда пользователь сможет начать игру. Сейчас API не вызывается, успешная публикация не имитируется: готовый пак открывает информационное окно. Незаполненный пак блокирует действие.
JSON доступен только в режиме суперадмина, включая проверку в обработчике экспорта. Параметр admin — локальный предпросмотр интерфейса, не серверная авторизация. При интеграции проверять роль и права на backend.

Блок публикации оформлен карточкой: название пака, статус, количество карт, готовность разделов, путь в профиле и действия. JSON видит только суперадмин. Компоновка на узких экранах складывается в одну колонку.
